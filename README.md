Job Portal Management System using MySQL

Project Overview

The Job Portal Management System is a database project developed using MySQL. It helps manage candidates, employers, job postings, applications, and interview details efficiently.

Objectives

- Store candidate details.
- Maintain employer and company information.
- Manage job postings and salary details.
- Track candidate applications.
- Maintain interview schedules and results.

Technologies Used

- MySQL
- SQL

Database Tables

1. Candidates
2. Employers
3. Jobs
4. Applications
5. Interviews

Key SQL Concepts Used

- Database and Table Creation
- Primary Keys and Foreign Keys
- Constraints
- INSERT, UPDATE, DELETE
- SELECT Queries
- WHERE, ORDER BY, GROUP BY
- Joins
- Aggregate Functions
- String Functions
- Date Functions
- Views
- Transactions
- Stored Procedures

How to Run the Project

1. Install MySQL Server and MySQL Workbench.
2. Open MySQL Workbench.
3. Open the PROJECT.sql file.
4. Execute the SQL statements.
5. Use SELECT queries to view the results.

Project File

- PROJECT.sql – Contains database creation, table creation, sample data, and SQL queries.

Conclusion

This project demonstrates practical knowledge of relational database management and SQL operations through a Job Portal Management System.
